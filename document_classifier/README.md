# Module 1 — Document Classification

This module implements a **Multi-Head Vision Transformer (ViT-Base)** for classifying government-issued identity documents.

## Predictions

The model jointly predicts:

- Document Type
- Document Side (Front / Back)
- Issuing State

## Files

- `module_1_document_classifier.ipynb` — Training and evaluation notebook
- `label_mappings.json` — Label mappings used during inference

> The trained model weights are hosted separately on Hugging Face.
